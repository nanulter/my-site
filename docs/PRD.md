# 사이트 설계도(PRD) — 무인문구 (MOOIN MOON9)

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
3D프린터로 제품을 복제하는 모습을 보여 주고 판매하며, 초등학생용 과학 실험 교재를 파는 무인문구 사이트.

## 2. 손님
- 누가: 초등학생 자녀를 둔 학부모
- 어디서 알고 오나: 홈페이지, 동네 맘카페·학부모 단톡, 인스타·블로그, 검색

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격 (실험 교재 값, 3D프린팅 복제·출력 비용)
2. 몇 학년용인지 (우리 아이 학년에 맞는지)
3. 안전한지 (재료·부품이 아이에게 안전한지)
4. 받는 방법·위치 (매장 위치, 방문 시간, 택배 여부)
- 궁금한 점을 물어볼 질문란이 있었으면 한다 → 이번엔 "자주 묻는 질문" 칸과 문의 폼으로 대신한다. 질문 게시판은 9번으로 보낸다.

## 4. 믿게 할 증거 (실제로 있는 것만)
- 교재·완성품 사진
- 3D프린터 시연 사진·영상: (준비 중)
- 경력·자격·안전 인증: (미정. 있으면 그때 넣는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 교재 구매 문의
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + "교재 구매 문의" 버튼
2. 실험 교재 — 교재·완성품 사진, 학년, 가격(미정이면 "문의")
3. 3D프린터 제품 복제 시연·판매 — 하는 일 소개(사진은 준비 중)
4. 자주 묻는 질문 — 가격 · 학년 · 안전 · 받는 방법·위치
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 원하는 교재·학년 (한 칸)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 온라인 결제
- 회원가입·로그인
- 질문 게시판
- 시연 예약 달력

## 10. 첫 화면 한 문장 후보
1. 초등 과학 실험 교재와 3D프린터 제품 복제, 무인문구에서 만나요.
2. 아이와 함께하는 과학 실험, 학년에 맞는 교재를 골라 드려요.
3. 3D프린터로 만드는 과정을 보고, 집에서는 실험 교재로 이어 가요.

## 11. 다음에 할 것
- 9번 기능 (온라인 결제, 회원가입·로그인, 질문 게시판, 시연 예약 달력)
- 3D프린터 시연 사진·영상 넣기
- 실제 후기가 생기면 후기 칸 채우기
- 8번 사실(가격·시간·위치·연락 방법) 채우기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
